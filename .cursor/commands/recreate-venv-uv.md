# Пересоздание виртуального окружения через uv

**Цель:** заново создать venv в корне текущего проекта (`bitrix24_chatbot_demo`).

**Условие:** на хосте установлен [uv](https://docs.astral.sh/uv/).

Выполнять из **корня репозитория** (`bitrix24_chatbot_demo`).

## Шаги

1. Удалить текущее окружение (если есть):
   ```bash
   rm -rf .venv
   ```

2. Создать venv и установить зависимости:
   ```bash
   uv venv
   uv sync
   ```
   В новых версиях uv достаточно `uv sync` — он создаст `.venv` при отсутствии.

3. Проверить запуск бота:
   ```bash
   uv run bitrix-bot --help
   ```
